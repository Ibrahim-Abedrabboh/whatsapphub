# Demo Data Seed — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `npm run seed:demo` command that populates the admin client with realistic, bilingual demo data across every shipped feature, idempotently, plus `--clear` to remove it.

**Architecture:** Pure helpers (deterministic `demoseed-` ids, prefixes, FK-safe clear order) live in `src/lib/demoSeed.ts` (typechecked + unit-tested). A tsx entrypoint `scripts/seed-demo.ts` resolves the admin client, runs per-feature seeder modules under `scripts/demo/`, and handles `--clear`. Every row uses a deterministic id so re-runs upsert and teardown is bounded to demo rows.

**Tech Stack:** TypeScript run via `tsx` (like the worker), Prisma, Vitest.

## Global Constraints

- TypeScript `strict` + `noUncheckedIndexedAccess`.
- **tsx-run files use relative imports** (`../src/lib/demoSeed`), NOT the `@/` alias — tsx does not resolve tsconfig paths (same rule as `src/worker`).
- Pure/DB-free logic goes in `src/lib/demoSeed.ts` so vitest (`src/**/*.test.ts`) and tsc cover it.
- **Safety (non-negotiable):** no BullMQ/queue imports, no `lib/whatsapp` or channel adapters, no network — Prisma reads/writes only. Rows written in final states.
- **Marker:** every seeded primary key is `demoseed-<entity>-<key>`. Display names/titles get a `Demo — ` prefix (except `Template.name`, which must stay lowercase-underscore — use `demo_*` names there).
- **Target client:** the resolved SUPERADMIN `clientId`, else `"default"`.
- Demo contacts use fake phones `9665000000NN` to avoid the `[clientId, phone]` unique constraint.
- Gate for the TS code: `npm run typecheck` · `npm test` · `SKIP_ENV_VALIDATION=1 npm run build`. The full seed is verified by running against a dev DB.

```ts
// Pure helpers for the demo-data seeder (scripts/seed-demo.ts). No DB access —
// kept here so vitest + tsc cover them. Every seeded row's primary key is
// `demoseed-<entity>-<key>`, which makes re-runs idempotent (upsert by id) and
// teardown bounded (delete where id startsWith the prefix).

export const DEMO_ID_PREFIX = "demoseed-";
export const DEMO_NAME_PREFIX = "Demo — ";

export function demoId(entity: string, key: string | number): string {
  return `${DEMO_ID_PREFIX}${entity}-${key}`;
}

export function isDemoId(id: string): boolean {
  return id.startsWith(DEMO_ID_PREFIX);
}

/** Prefix a display name once; safe to apply to an already-prefixed name. */
export function demoName(s: string): string {
  return s.startsWith(DEMO_NAME_PREFIX) ? s : `${DEMO_NAME_PREFIX}${s}`;
}

/** Reserved fake phone range so demo contacts never clash with real ones. */
export function demoPhone(n: number): string {
  return `9665${String(n).padStart(8, "0")}`;
}

// Prisma model delegate names in FK-safe delete order (children first). The
// entrypoint iterates this for `--clear`. `contactListMembership` has a
// composite PK (no id) — the entrypoint clears it by demo listId.
export const CLEAR_ORDER = [
  "messageEvent",
  "broadcastRecipient",
  "broadcast",
  "internalNote",
  "message",
  "order",
  "conversation",
  "contactListMembership",
  "segment",
  "product",
  "commerceCatalog",
  "template",
  "contactList",
  "contact",
  "cannedReply",
  "knowledgeDoc",
  "automationRule",
  "flow",
] as const;
```

Create `scripts/seed-demo.ts`:

```ts
// Demo-data seeder. Populates the admin client with realistic bilingual data
// across every shipped feature, idempotently. Run: `npm run seed:demo`
// Remove: `npm run seed:demo -- --clear`. Pure Prisma writes only — no queue,
// no WhatsApp API, no real sends.
import { PrismaClient } from "@prisma/client";
import { CLEAR_ORDER, DEMO_ID_PREFIX } from "../src/lib/demoSeed";
import { seed as seedContacts } from "./demo/contacts";
import { seed as seedBroadcasts } from "./demo/broadcasts";
import { seed as seedInbox } from "./demo/inbox";
import { seed as seedEngagement } from "./demo/engagement";
import { seed as seedCommerce } from "./demo/commerce";

const prisma = new PrismaClient();

/** The SUPERADMIN's client, else the first ADMIN's, else "default". */
async function resolveAdminClientId(): Promise<string> {
  const admin =
    (await prisma.user.findFirst({ where: { role: "SUPERADMIN" }, select: { clientId: true } })) ??
    (await prisma.user.findFirst({ where: { role: "ADMIN" }, select: { clientId: true } }));
  return admin?.clientId ?? "default";
}

async function clearDemo(): Promise<void> {
  for (const model of CLEAR_ORDER) {
    const where =
      model === "contactListMembership"
        ? { listId: { startsWith: DEMO_ID_PREFIX } }
        : { id: { startsWith: DEMO_ID_PREFIX } };
    // eslint-disable-next-line @typescript-eslint/no-explicit-any
    const res = await (prisma as any)[model].deleteMany({ where });
    console.log(`  cleared ${model}: ${res.count}`);
  }
}

async function main() {
  const clear = process.argv.includes("--clear");
  const clientId = await resolveAdminClientId();
  console.log(`Demo seed → client "${clientId}"${clear ? " (clear)" : ""}`);

  if (clear) {
    await clearDemo();
    console.log("Demo data cleared.");
    return;
  }

  // Ordered so parents exist before children reference them.
  await seedContacts(prisma, clientId);
  await seedBroadcasts(prisma, clientId);
  await seedInbox(prisma, clientId);
  await seedEngagement(prisma, clientId);
  await seedCommerce(prisma, clientId);
  console.log("Demo data seeded.");
}

main()
  .catch((e) => {
    console.error(e);
    process.exitCode = 1;
  })
  .finally(() => prisma.$disconnect());
```

Note: the `(prisma as any)[model]` indexing in `clearDemo` is the one deliberate `any` — Prisma delegate names are dynamic here. Keep it localized.

```ts
import type { PrismaClient } from "@prisma/client";
import { demoId, demoName, demoPhone } from "../../src/lib/demoSeed";

const CONTACTS = [
  { n: 1, name: "Sara Al-Otaibi", tags: ["vip", "riyadh"], optedOut: false },
  { n: 2, name: "Mohammed Al-Ghamdi", tags: ["vip"], optedOut: false },
  { n: 3, name: "Layla Hassan", tags: ["jeddah"], optedOut: false },
  { n: 4, name: "Omar Khalid", tags: ["new"], optedOut: false },
  { n: 5, name: "Noura Al-Rashid", tags: ["vip", "jeddah"], optedOut: false },
  { n: 6, name: "Faisal Al-Dossary", tags: [], optedOut: true },
];

export async function seed(prisma: PrismaClient, clientId: string): Promise<void> {
  for (const c of CONTACTS) {
    const id = demoId("contact", c.n);
    await prisma.contact.upsert({
      where: { id },
      create: {
        id, clientId, phone: demoPhone(c.n), name: c.name,
        attributes: { source: "demo", city: c.tags.includes("jeddah") ? "Jeddah" : "Riyadh" },
        tags: c.tags, optedOut: c.optedOut,
      },
      update: { name: c.name, tags: c.tags, optedOut: c.optedOut },
    });
  }

  const listId = demoId("list", "vip");
  await prisma.contactList.upsert({
    where: { id: listId },
    create: { id: listId, clientId, name: demoName("VIP customers") },
    update: { name: demoName("VIP customers") },
  });

  // Memberships: contacts 1, 2, 5 are VIP. Composite PK → upsert by (contactId,listId).
  for (const n of [1, 2, 5]) {
    const contactId = demoId("contact", n);
    await prisma.contactListMembership.upsert({
      where: { contactId_listId: { contactId, listId } },
      create: { contactId, listId },
      update: {},
    });
  }

  const segmentId = demoId("segment", "active");
  await prisma.segment.upsert({
    where: { id: segmentId },
    create: {
      id: segmentId, clientId, name: demoName("Active in Riyadh"),
      rules: { all: [{ field: "attributes.city", op: "eq", value: "Riyadh" }] },
    },
    update: { name: demoName("Active in Riyadh") },
  });

  console.log("  contacts + list + segment seeded");
}
```

Note: `contactList` unique is `[clientId, name]`; upserting by `id` is fine as long as the demo name is unique in the client (the `Demo — ` prefix ensures that). The `segment.rules` shape is illustrative demo content; it is stored as opaque JSON.

```ts
import type { PrismaClient } from "@prisma/client";
import { demoId } from "../../src/lib/demoSeed";

const STATUSES = ["READ", "READ", "DELIVERED", "SENT", "READ", "FAILED"] as const;

export async function seed(prisma: PrismaClient, clientId: string): Promise<void> {
  const templateId = demoId("template", "eid");
  await prisma.template.upsert({
    where: { id: templateId },
    create: {
      id: templateId, name: "demo_eid_promo", language: "ar",
      category: "MARKETING", variableCount: 1, status: "APPROVED",
    },
    update: { status: "APPROVED" },
  });

  const listId = demoId("list", "vip");
  const broadcastId = demoId("broadcast", "eid");
  const now = new Date();
  const yesterday = new Date(now.getTime() - 24 * 3600 * 1000);
  await prisma.broadcast.upsert({
    where: { id: broadcastId },
    create: {
      id: broadcastId, clientId, templateId, listId, status: "COMPLETED",
      totalCount: 6, sentCount: 5, failedCount: 1,
      startedAt: yesterday, completedAt: yesterday,
    },
    update: { status: "COMPLETED", sentCount: 5, failedCount: 1 },
  });

  for (let i = 0; i < STATUSES.length; i++) {
    const n = i + 1;
    const status = STATUSES[i]!;
    const recipientId = demoId("rcpt", n);
    const wamid = `wamid.demoseed.${broadcastId}.${n}`;
    await prisma.broadcastRecipient.upsert({
      where: { id: recipientId },
      create: {
        id: recipientId, broadcastId, contactId: demoId("contact", n), status, wamid,
        error: status === "FAILED" ? "(131049) outside 24h window" : null,
      },
      update: { status },
    });
  }

  // Two READ recipients tapped a button.
  for (const n of [1, 5]) {
    const eventId = demoId("evt", n);
    const wamid = `wamid.demoseed.${broadcastId}.${n}`;
    await prisma.messageEvent.upsert({
      where: { id: eventId },
      create: { id: eventId, recipientId: demoId("rcpt", n), wamid, type: "click", payload: { label: "Shop now" } },
      update: {},
    });
  }

  console.log("  template + broadcast + recipients + events seeded");
}
```

Note: `Broadcast.templateId`/`listId` are required; both reference demo rows from Tasks 3–4. `Template` upsert is by `id` (its `[name, language]` unique is satisfied by the unique `demo_eid_promo`/`ar` pair).

```ts
const CONVS = [

export async function seed(prisma: PrismaClient, clientId: string): Promise<void> {
  const admin = await prisma.user.findFirst({ where: { clientId }, select: { id: true } });
  const base = Date.now() - 3 * 3600 * 1000;

  for (const c of CONVS) {
    const convId = demoId("conv", c.key);
    const lastAt = new Date(base + c.turns.length * 60000);
    await prisma.conversation.upsert({
      where: { id: convId },
      create: {
        id: convId, clientId, phone: c.peer, channel: c.channel,
        contactId: demoId("contact", c.contactN), lastPreview: c.preview,
        lastInboundAt: lastAt, lastMessageAt: lastAt, unread: c.channel === "WHATSAPP" ? 0 : 1,
        status: "OPEN",
      },
      update: { lastPreview: c.preview, lastMessageAt: lastAt },
    });

    for (let i = 0; i < c.turns.length; i++) {
      const t = c.turns[i]!;
      const msgId = demoId("msg", `${c.key}-${i}`);
      await prisma.message.upsert({
        where: { id: msgId },
        create: {
          id: msgId, clientId, conversationId: convId, channel: c.channel,
          direction: t.dir, type: "text", text: t.text,
          status: t.dir === "OUT" ? "READ" : null,
          createdAt: new Date(base + i * 60000),
        },
        update: { text: t.text },
      });
    }
  }

  // One internal note on the WhatsApp conversation.
  const noteId = demoId("note", 1);
  await prisma.internalNote.upsert({
    where: { id: noteId },
    create: {
      id: noteId, clientId, conversationId: demoId("conv", "wa"),
      authorId: admin?.id ?? null, body: "VIP customer — prioritise follow-up.",
    },
    update: { body: "VIP customer — prioritise follow-up." },
  });

  console.log("  conversations + messages + note seeded");
}
```

Note: `Conversation` unique is `[clientId, channel, phone]`; each demo peer is unique per channel. `Message.wamid` is left null (nullable, unique only when set), avoiding collisions.

```ts
import type { PrismaClient } from "@prisma/client";
import { demoId, demoName } from "../../src/lib/demoSeed";

export async function seed(prisma: PrismaClient, clientId: string): Promise<void> {
  const canned = [
    { key: "hours", title: "Business hours", shortcut: "/hours", body: "We're open Sun–Thu, 9am–6pm. How can we help, {{name}}?" },
    { key: "shipping", title: "Shipping info", shortcut: "/ship", body: "Orders ship in 2–3 business days across the Kingdom." },
  ];
  for (const c of canned) {
    const id = demoId("canned", c.key);
    await prisma.cannedReply.upsert({
      where: { id },
      create: { id, clientId, title: demoName(c.title), shortcut: c.shortcut, body: c.body },
      update: { body: c.body },
    });
  }

  const docs = [
    { key: "returns", title: "Returns policy", content: "Items can be returned within 14 days with the original receipt for a full refund." },
    { key: "delivery", title: "Delivery areas", content: "We deliver to Riyadh, Jeddah, and Dammam. Same-day delivery is available in Riyadh." },
  ];
  for (const d of docs) {
    const id = demoId("kb", d.key);
    await prisma.knowledgeDoc.upsert({
      where: { id },
      create: { id, clientId, title: demoName(d.title), content: d.content, source: "demo" },
      update: { content: d.content },
    });
  }

  const welcomeId = demoId("rule", "welcome");
  await prisma.automationRule.upsert({
    where: { id: welcomeId },
    create: {
      id: welcomeId, clientId, name: demoName("Welcome on 'hi'"), enabled: true,
      trigger: { type: "keyword", keywords: ["hi", "hello", "مرحبا"] },
      action: { type: "sendText", body: "Hi {{name}}! Thanks for reaching out — how can we help?" },
    },
    update: { enabled: true },
```

```ts
import type { PrismaClient } from "@prisma/client";
import { demoId, demoPhone } from "../../src/lib/demoSeed";

export async function seed(prisma: PrismaClient, clientId: string): Promise<void> {
  // CommerceCatalog.clientId is @unique — only create a demo catalog if the
  // client has none, so we never collide with a real one.
  const existing = await prisma.commerceCatalog.findUnique({ where: { clientId }, select: { id: true } });
  if (!existing) {
    const catalogId = demoId("catalog", 1);
    await prisma.commerceCatalog.upsert({
      where: { id: catalogId },
      create: { id: catalogId, clientId, metaCatalogId: "demo-catalog", name: "Demo — Catalog" },
      update: {},
    });
  }

  const products = [
    { n: 1, retailerId: "DEMO-SKU-001", name: "Dates gift box", priceText: "SAR 120.00" },
    { n: 2, retailerId: "DEMO-SKU-002", name: "Arabic coffee set", priceText: "SAR 85.00" },
    { n: 3, retailerId: "DEMO-SKU-003", name: "Oud incense", priceText: "SAR 45.00" },
  ];
  for (const p of products) {
    const id = demoId("product", p.n);
    await prisma.product.upsert({
      where: { id },
      create: {
        id, clientId, retailerId: p.retailerId, name: p.name,
        priceText: p.priceText, currency: "SAR", availability: "in stock",
      },
      update: { name: p.name, priceText: p.priceText },
    });
  }

  const orders = [
    { n: 1, contactN: 1, status: "CONFIRMED", total: "205.00", items: [{ retailerId: "DEMO-SKU-001", qty: 1 }, { retailerId: "DEMO-SKU-002", qty: 1 }] },
    { n: 2, contactN: 3, status: "NEW", total: "45.00", items: [{ retailerId: "DEMO-SKU-003", qty: 1 }] },
  ];
  for (const o of orders) {
    const id = demoId("order", o.n);
    await prisma.order.upsert({
      where: { id },
      create: {
        id, clientId, contactId: demoId("contact", o.contactN), phone: demoPhone(o.contactN),
        conversationId: o.contactN === 1 ? demoId("conv", "wa") : null,
        items: o.items, itemCount: o.items.length, total: o.total, currency: "SAR", status: o.status,
      },
      update: { status: o.status },
    });
  }

  console.log("  catalog + products + orders seeded");
}
```

Note: `Order.total` is `Decimal` — Prisma accepts a decimal string (`"205.00"`). `conversationId`/`contactId` are optional and point at demo rows.
