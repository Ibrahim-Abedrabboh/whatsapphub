WhatsApp Cloud APIواتساب كلاود API

  • Phone Number IDمعرّف رقم الهاتف (Phone Number ID)WhatsApp → API Setupواتساب ← إعداد الـ API
  • WhatsApp Business Account ID (WABA)معرّف حساب واتساب للأعمال (WABA)WhatsApp → API Setupواتساب ← إعداد الـ API
  • Access Tokenرمز الوصول (Access Token) — permanent / system-user token— دائم / لمستخدم نظامBusiness Settings → System Users → Generate tokenإعدادات الأعمال ← مستخدمو النظام ← توليد رمز
  • App IDمعرّف التطبيق (shared) — for media & template-header uploads(مشترك) — لرفع الوسائط وترويسات القوالب
⚠️ Warning:⚠️ تنبيه: The Phone Number ID and the WABA ID are different numbers, and neither is the Business Portfolio ID. Take both straight from WhatsApp → API Setup.معرّف رقم الهاتف ومعرّف WABA رقمان مختلفان، ولا أحدهما هو معرّف حافظة الأعمال. خذهما مباشرة من واتساب ← إعداد الـ API.
💡 Tip:💡 نصيحة: The easiest route is the built-in one-click Embedded Signup — log in with Facebook, pick your number, and the WABA, Phone Number ID, and token are captured automatically.أسهل طريقة هي التسجيل المُدمج بنقرة واحدة — سجّل الدخول بفيسبوك، واختر رقمك، فيُلتقط WABA ومعرّف الرقم والرمز تلقائيًا.

📝 Note:📝 ملاحظة: Messenger and the Facebook Page share the same Page ID + Page Access Token — one token covers both.ماسنجر وصفحة فيسبوك يتشاركان نفس معرّف الصفحة ورمز وصولها — رمز واحد يكفي لكليهما.

Instagram Inbox + Instagram Pageصندوق إنستغرام + صفحة إنستغرام

  • Instagram Business Account IDمعرّف حساب إنستغرام للأعمال — the IG "asset" id used to route inbound— معرّف "أصل" إنستغرام الذي تُوجَّه به الرسائل الواردةThe IG Professional account linked to the Pageحساب إنستغرام الاحترافي المرتبط بالصفحة
  • Page Access Tokenرمز وصول الصفحة of the linked Facebook Pageلصفحة فيسبوك المرتبطةInstagram messaging uses the connected Page's tokenمراسلة إنستغرام تستخدم رمز الصفحة المتّصلة
  • IG account is a Professional (Business/Creator) account, linked to the Pageحساب إنستغرام احترافي (أعمال/منشئ) ومرتبط بالصفحة
  • App granted instagram_manage_messages / instagram_basicمُنح التطبيق instagram_manage_messages / instagram_basic
⚠️ Warning:⚠️ تنبيه: Instagram DMs cannot be managed from a personal IG account — convert it to a Professional account and link it to the Facebook Page first.لا يمكن إدارة رسائل إنستغرام من حساب شخصي — حوّله إلى حساب احترافي واربطه بصفحة فيسبوك أولًا.

Before You Go Liveقبل الانطلاق

⚠️ App Review:⚠️ مراجعة التطبيق: WhatsApp works with a verified number right away, but Messenger and Instagram messaging only reach the public after Meta approves your app's permissions (App Review). Until then they work only for app testers/roles — plan time for this review.يعمل واتساب برقم مُوثَّق فورًا، لكن مراسلة ماسنجر وإنستغرام لا تصل للعموم إلا بعد اعتماد ميتا لصلاحيات تطبيقك (مراجعة التطبيق). وحتى ذلك الحين تعمل لمختبِري التطبيق فقط — فخصّص وقتًا للمراجعة.
✅ Success:✅ نتيجة: With the shared foundation, each channel's IDs, and one long-lived token per channel, your WhatsApp, Messenger, and Instagram conversations all flow into the same unified team inbox.مع الأساس المشترك، ومعرّفات كل قناة، ورمز طويل الأمد لكل قناة، تتدفّق محادثات واتساب وماسنجر وإنستغرام كلها إلى صندوق الفريق الموحّد نفسه.
