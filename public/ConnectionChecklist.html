Shared Foundation

needed for every channel
  • Meta App createddevelopers.facebook.com → Create App
  • Meta App IDApp → Settings → Basic
  • Meta App Secret — verifies every incoming webhookApp → Settings → Basic
  • Business Portfolio owning your number, Page & Instagram accountbusiness.facebook.com
  • Webhook Verify Token — a secret phrase you chooseAny string; used once when Meta connects the webhook
⚠️ Warning: The App Secret and Verify Token are reused across all channels — you don't need a separate one per channel.
1

WhatsApp Cloud API

  • Phone Number IDWhatsApp → API Setup
  • WhatsApp Business Account ID (WABA)WhatsApp → API Setup
  • Access Token — permanent / system-user tokenBusiness Settings → System Users → Generate token
  • App ID (shared) — for media & template-header uploadsFrom the Shared Foundation
⚠️ Warning: The Phone Number ID and the WABA ID are different numbers, and neither is the Business Portfolio ID. Using the wrong one makes template features fail — take both straight from WhatsApp → API Setup.
💡 Tip: The easiest route is the built-in one-click Embedded Signup — log in with Facebook, pick your number, and the WABA, Phone Number ID, and token are captured automatically. No manual copying.
2

Facebook Page + Messenger

  • Facebook Page IDThe Page → About / Page settings
  • Page Access Token (long-lived)Generated from the app with the pages_messaging permission
  • Page subscribed to the app's webhookFields: messages, messaging_postbacks
📝 Note: Messenger and the Facebook Page share the same Page ID + Page Access Token — one token covers both.
3

Instagram Inbox + Instagram Page

  • Instagram Business Account ID — the IG "asset" id used to route inboundThe IG Professional account linked to the Page
  • Page Access Token of the linked Facebook PageInstagram messaging uses the connected Page's token
  • IG account is a Professional (Business/Creator) account, linked to the Page
  • App granted instagram_manage_messages / instagram_basic
⚠️ Warning: Instagram DMs cannot be managed from a personal IG account — convert it to a Professional account and link it to the Facebook Page first.
4

request these on the app

Before You Go Live

⚠️ App Review: WhatsApp works with a verified number right away, but Messenger and Instagram messaging only reach the public after Meta approves your app's permissions (App Review). Until then they work only for people added as testers/roles on the app — plan time for this review.
✅ Success: With the shared foundation, each channel's IDs, and one long-lived (non-expiring) token per channel, your WhatsApp, Messenger, and Instagram conversations all flow into the same unified team inbox.
